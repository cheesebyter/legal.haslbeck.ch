# Rechtstexte

Dieser Ordner enthält versionierte deutsche Ausgangstexte und deren
Übersetzungen als Markdown-Module.

Die deutschen AGB-Ausgangsklauseln liegen unter `terms/de/`. Sie sind
modulweise versioniert und bis zur dokumentierten juristischen Prüfung
ausdrücklich nicht zur produktiven Verwendung freigegeben.
