Service description

CaptHook receives signed webhook events, checks them against configured rules and forwards matching events to Slack, Discord or Microsoft Teams. Free includes up to 3 pipes, 2 destinations per pipe and 500 events per month; Pro includes up to 50 pipes, 10 destinations per pipe, 50000 events per month and email support. The scope described for the selected plan when the contract is formed applies. Functions not expressly promised are not owed.
